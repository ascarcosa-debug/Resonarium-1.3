Proteger la app con contraseña

  1. Elige el index.html sin proteger (el del paquete normal).
  2. Escribe una contraseña nueva (mejor una frase larga de 4 palabras o más).
  3. Descarga el index.html protegido y súbelo a GitHub en lugar del original.

Todo ocurre en tu dispositivo: la contraseña y el archivo no se envían a ningún sitio. No subas a GitHub la versión sin proteger.
